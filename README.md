# CatalogMind

**A multi-tenant conversational commerce API.** A merchant uploads a product feed and
gets a live, grounded, streaming shopping assistant scoped to their catalog — in under
60 seconds, via API.

> Status: **in development.** This README is rewritten on Day 7 with the measured
> eval results. Every number published here is regenerated by `make eval` — none are
> hand-typed.

## Why this exists

Conversational product discovery is easy to demo and hard to operate. The hard parts are
not the LLM call — they are tenant isolation, catalog heterogeneity, retrieval quality you
can actually measure, and cost per query. This project implements those parts.

## Quickstart

```bash
make install     # Python 3.12 venv + deps
cp .env.example .env && $EDITOR .env    # add AWS_BEARER_TOKEN_BEDROCK
make up          # weaviate + postgres + mongo + redis
make migrate
make seed        # provision 3 demo merchants, ingest their catalogs
make dev         # http://localhost:8000/docs
```
